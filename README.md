# ECHO//BREAK

ブラウザで動く一人称（FPS）アリーナシューター。PC でもスマホでも同じページで遊べます。

## オリジナル要素：ECHO システム
直近 5 秒間の「自分の動きと射撃」が常に記録されています。ECHO を発動すると、過去の自分がホログラムとして再生されます。
- ホログラムは記録どおりに動き、同じ武器で撃つ（近くの敵へ少し吸い付く）
- 敵の多くはホログラムを狙うので、おとりになる
- 再生が終わると爆発して、周りの敵にダメージ
- ECHO ゲージは、敵に与えたダメージと時間経過でたまる

## モード
- **NPC戦**：ウェーブ制のサバイバル。難易度は EASY / NORMAL / HARD
- **チュートリアル**：全12ステップ（視点 → 移動 → 二段ジャンプ → ダッシュ → スライディング → ジャンプパッド → フック → 射撃 → 武器 → ショックウェーブ → ECHO → 実戦）
- **対人戦**：今後追加予定（ホーム画面に COMING SOON として表示）

## 起動のしかた
ES モジュール（JavaScript を分けて読み込むしくみ）を使っているので、ファイルを直接開くのではなく、ローカルサーバーを立てて開きます。

```bash
cd echo-break && python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。
3D描画ライブラリの Three.js（0.170.0）は CDN から読み込むので、インターネット接続が必要です。

公開版：https://rucker-af.github.io/echo-break/ （スマホ・PCどちらでも遊べます）

## 素材
床・壁・箱の写真素材と、光の元にしている夜の屋上写真（HDRI）は [Poly Haven](https://polyhaven.com) の CC0 素材です。
- hangar_concrete_floor / metal_plate_02 / metal_plate / container_side（各1k）
- rooftop_night（HDRI 1k）

アバターのモデルは RobotExpressive（作者：Tomás Laulhé / Quaternius、CC0。three.js の作例から取得）を、キャラごとに色と体格を変えて使っています。

「軽量」画質では色の画像だけを読み込み、凹凸・ざらつき・HDRI・接地面の影（GTAO）は使いません。

## ファイル構成
- `index.html` … 画面の骨組み（HUD・メニュー・タッチボタン）
- `css/style.css` … 見た目
- `js/main.js` … 全体の管理（状態の切り替え・描画・ループ）
- `js/world.js` … ステージ・当たり判定・空・街並み
- `js/player.js` … プレイヤーの移動とスキル
- `js/weapons.js` … 武器の性能と手元の銃モデル
- `js/combat.js` … 射撃判定・爆発・ショックウェーブ・回復オーブ
- `js/enemies.js` … 敵の種類・AI・敵の弾
- `js/echo.js` … ECHO システム
- `js/modes.js` … NPC戦とチュートリアル
- `js/effects.js` … パーティクル・弾道・光
- `js/ui.js` … HUD の表示
- `js/input.js` … キーボード・マウス・タッチ入力
- `js/audio.js` … 効果音（WebAudio で合成。音声ファイルは使わない）
- `assets/` … 写真素材（テクスチャ）とHDRI

## 対人戦に向けたメモ
- 入力は `input.js` で「アクション名」にまとめてあるので、ネット越しの入力も同じ形で流し込める
- 射撃処理 `combat.fireShot(def, origin, dir, muzzle, owner)` は、撃ち手（owner）を引数で受け取る作りなので、他プレイヤーにも使い回せる
- 追加するには、WebSocket などの通信サーバーと、サーバー側での当たり判定（チート対策）が必要
